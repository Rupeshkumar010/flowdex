# FlowDEX - Multi-Pair OTC Trading on Arc Testnet

Professional trading platform with 5 trading pairs.

## Features

- ✅ 5 Trading Pairs: BTC, ETH, SOL, XRP, PEPE
- ✅ Real-time Price Charts
- ✅ Order Book (Buy/Sell)
- ✅ Market & Limit Orders
- ✅ Leverage Trading (1-20x)
- ✅ Portfolio Management
- ✅ Position Tracking
- ✅ Arc Testnet Integration

## Quick Start

```bash
npm install
npm run dev
```

Visit http://localhost:3000

## Deployment

Deploy to Vercel with one click!

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Wagmi
- Tailwind CSS

Built on Arc Testnet. Testnet assets have no real-world value.
